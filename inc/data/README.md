# دادهٔ مشترک شهرهای ایران

`iran-cities.json` منبع واحد فهرست شهرها برای checkout ووکامرس و جریان انتخاب نشانی/نقشه است. کلیدها نام فارسی استان‌ها هستند تا DSN و WooCommerce از همان پاسخ استفاده کنند؛ WooCommerce در PHP این نام‌ها را به کد رسمی استان تبدیل می‌کند. فهرست قدیمی قالب همچنان مقدم می‌ماند و ادغام آن فقط گزینه‌های جدید را اضافه می‌کند.

- مجموعهٔ پایه: [`sajaddp/list-of-cities-in-Iran`](https://github.com/sajaddp/list-of-cities-in-Iran)، مجوز GPL-3.0؛ متن مجوز در `iran-cities-GPL-3.0.txt` و یادداشت منبع در `../dsn-address-flow/CITIES-LICENSE.txt`.
- افزوده‌ها: [`jd1378/iran-cities-json`](https://github.com/jd1378/iran-cities-json)، فایل‌های `shahr.json` و `ostan.json`، commit `2766b261efd9ac66b2e48c2fa58e075cb892f170`؛ مجوز MIT و متن کامل در `iran-cities-MIT-LICENSE.txt`.
- نام‌های دو منبع با نرمال‌سازی فاصله/نیم‌فاصله/خط تیره و «ی/ك» تطبیق داده شده‌اند؛ نام اصلی داده برای نمایش حفظ می‌شود. ۲۹ نام منحصربه‌فرد از مجموعهٔ MIT به فهرست پایه افزوده شده است.
- فهرست‌های بالادستی ممکن است همهٔ آبادی‌ها یا نام‌های سفارشی کاربران را پوشش ندهند؛ شهرهای ناشناخته همچنان در جریان نشانی مجازند.
