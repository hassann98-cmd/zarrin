# دادهٔ شهرهای ایران

`iran-cities.json` افزوده‌های شهر به نقشهٔ قدیمی پوسته است؛ فهرست قبلیِ ۲۶۰تایی در `inc/woocommerce.php` نگه داشته شده و همچنان اولویت نمایش دارد.

- منبع: [`jd1378/iran-cities-json`](https://github.com/jd1378/iran-cities-json)، فایل‌های `shahr.json` و `ostan.json`
- نسخهٔ منبع: commit `2766b261efd9ac66b2e48c2fa58e075cb892f170`
- مجوز: MIT؛ متن کامل مجوز در `iran-cities-MIT-LICENSE.txt` است.
- منبع بالادستی در README آن مخزن از کار `ahmadazizi/iran-cities` نیز قدردانی می‌کند.
- از ۱٬۳۲۴ رکورد منبع، یک تکرار درون‌استانی حذف شد. پس از تطبیق با نقشهٔ قدیمی، JSON شامل ۱٬۰۸۷ نام افزوده است؛ خروجی ادغام‌شده ۱٬۳۴۷ گزینه در ۳۱ کد استان ووکامرس دارد.
- نام اصلی برای نمایش و ذخیره حفظ می‌شود. یکسان‌سازی «ی/ك» عربی/فارسی و فاصله، نیم‌فاصله و خط تیره فقط برای حذف تکرار و تشخیص تطبیق استان/شهر است؛ مقدار ذخیره‌شده بازنویسی نمی‌شود.

فهرست منبع ممکن است همهٔ آبادی‌ها یا نام‌های سفارشی کاربران را پوشش ندهد. به همین دلیل اعتبارسنجی فقط شهر شناخته‌شده‌ای را که به استان دیگری تعلق دارد رد می‌کند و نام‌های ناشناخته را مسدود نمی‌کند.
