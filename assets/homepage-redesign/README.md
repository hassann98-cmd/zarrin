# JLuxe homepage redesign assets

This directory currently contains lightweight, theme-independent SVG icon artwork only. The five icons are original minimal trust/offer marks and do not include product claims or product photography.

| File | Use |
|---|---|
| `svg/trust-delivery.svg` | Delivery icon |
| `svg/trust-secure-payment.svg` | Secure-payment icon |

No lifestyle hero/banner images are included yet. They must be staged from real, published WooCommerce product photos; the current workspace does not contain the live WordPress media library, product records, or database credentials. Stock-like placeholder imagery was discarded rather than presented as genuine JLuxe products. These SVG files are not automatically registered in WordPress or attached to homepage settings.
